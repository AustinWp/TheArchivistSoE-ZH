# PD2-SOE S1 更新文档（国服 SOL 第一赛季）

> **原始文档**：腾讯文档 <https://docs.qq.com/doc/DT1ZyWXpWZnpiVUti>（《PD2-SOE S1 Patch Notes Final》）
> **正式服上线**：2026-09-11
> **本文件用途**：S1 赛季页面的**唯一文本来源**；原文照录，未作改写。
> **交叉验证结论**见同目录 `s1-verification.md`。

20 年前，我在同学家玩暗黑，29 级的法师穿上了第一次出的海蛇皮，还在疑惑：不是加所有技能吗？怎么还是不能用冰封球？没想到多年后的今天，能在大家的帮助下，把战网开起来。感谢一路支持和帮忙的朋友，特别感谢 CEO（真时间漩涡）的无私帮助。在 S1 开始前，也分享一下关于最近我做的一些改动思路。

我也是一名业余玩家，对游戏的理解还是不足的。这次做技能调整时也发现，有些改动看起来简单，实际影响却比预想中更广：比如增强熊人变化，受益的不只是熊德，也可能提高其他职业变熊后的强度；有的技能之前是攻坚技能，不应该按照通用去调整，召唤物的增强也不是把伤害、生命和抗性的数字往上填就行，还要考虑配装、加成和实际战斗表现。只靠不断堆数值，很容易就走向大家调侃的暗黑3的“亿兆京”，或者变成所有职业都是不同颜色的法师，这也不是想要的方向。

目前给我自己的定位，是在 PD2 和 PD2SOE 的基础上持续优化游玩过程和战网版本，主要精力仍会放在易用性和体验上，比如机遇石、掉落节奏、战网相关优化、之前做的自动拾取材料页，以及之后的超级大箱子，这样让大家既有收获，也有持续投入的空间。后续也会继续跟进 PD2 和 PD2SOE 的新赛季、新版本，在上游基础上持续优化。

而对于技能和装备的调整会更谨慎一些。大家反馈的问题会继续关注，有依据、能验证的地方也会做小幅优化；更大范围的平衡调整，至少需要我有更扎实的水平和更深入的理解。现阶段先把这些体验做好，让大家在熟悉的暗黑里玩得更方便、更有那种“哇金色传说”，这是我接下来最想做好的事。

## 机制说明（非本次平衡改动）

以下解释当前 SOE 的技能范围、技能增益效果和技能频率属性。这些属性各有适用技能，不能理解为所有技能都自动受益。电新星、霜之新星接入范围属性属于上文列出的 S1 改动；本节只是解释计算方式，没有额外修改数值。

下面按“怎么计算、配装后有什么变化、哪些技能受益”分别说明。游戏按整数和整帧计算，小数示例为取整前的结果。

### 技能范围：百分比折算系数与固定范围

装备上的“百分比技能范围”先转换为一个范围计算系数，并非直接按装备标注的百分比扩大实际半径或面积：

`P＝70 × X ÷（X＋18）`

X 为累计百分比技能范围属性值，例如 +10% 取 X＝10；P 为折算后的百分比系数。以下按非负属性值、不取整展示：

| 装备累计百分比技能范围 X | 范围计算系数 P |
|---|---|
| +0% | 0% |
| +5% | 约 15.2% |
| +10% | 25% |
| +18% | 35% |
| +42% | 49% |
| +72% | 56% |

低数值时系数可能高于装备标注；继续堆叠仍有效，但每增加一点带来的提升逐渐减少。该百分比系数趋近 70%，不是所有技能最终半径最多增加 70%，因为固定范围和技能自身成长还会参与计算。

多数直接计算范围的公式可概括为：

`范围＝（技能基础范围＋固定范围）×（1＋P÷100）`

技能基础范围可能包含技能等级、基础点或技能自身上限，不能只看 1 级数值。

固定范围先加到底数，再一起乘百分比系数；固定范围本身不经过上述递减曲线。因此固定范围和百分比范围可以相互配合。

对普通圆形范围技能，可以用半径理解；连锁、索敌等技能则扩大对应的搜索距离。

以基础半径 6 码、符合上述通式的圆形技能为例，忽略取整：

| 配装增加的范围属性 | 计算后的半径 | 相对原半径 |
|---|---|---|
| 只有 +10% 技能范围 | 6×1.25＝7.5 码 | 增加 25% |
| 只有 +2 码固定范围 | 6＋2＝8 码 | 增加约 33.3% |
| +10% 技能范围，同时 +2 码固定范围 | （6＋2）×1.25＝10 码 | 增加约 66.7% |
| +18% 技能范围，同时 +2 码固定范围 | （6＋2）×1.35＝10.8 码 | 增加 80% |

固定范围对基础范围较小的技能，相对提升更明显。范围扩大不会增加每次命中的伤害；有独立上限或特殊范围机制的技能，按各自规则计算。

“近战溅射范围”是另一类属性，不套用这里的百分比技能范围公式。

**电新星、霜之新星**：加快向外扩散，扩大覆盖。这两种技能的圆环由向外运动的弹体组成，范围属性提高的是初始扩散速度，弹体持续时间保持不变。固定范围也会转换为额外的扩散速度，并与百分比系数相乘。

只有百分比技能范围、没有固定范围时，两种新星按公式计算出的初始扩散速度变化相同：

| 装备累计百分比技能范围 | 初始扩散速度相对原值的提升（计入公式取整） |
|---|---|
| +0% | 0% |
| +5% | +12.5% |
| +10% | +25% |
| +18% | 约 +33.3% |
| +42% | 约 +45.8% |
| +72% | 约 +54.2% |

例如，+10% 技能范围会让两种新星的初始扩散速度提高 25%；再增加固定范围，还会追加一部分速度。因为两种新星的弹体持续时间不同，同一固定范围属性会分别换算成对应的速度增量。这张表表示起始扩散速度，不是最终命中半径；新星不能直接套用上面普通圆形技能的半径例子。

受技能范围影响的职业技能：根据技能类型，扩大爆炸、覆盖、索敌或弹跳范围；不会同时扩大技能中所有互不相关的部分。

| 职业 | 技能 |
|---|---|
| 亚马逊 | 爆裂箭、牺牲之箭、冻结之箭、闪电攻击；另有冻结之箭的独立变体 |
| 法师 | 地狱之火、霜之新星、火球、新星、闪电齐射、连锁闪电、陨石、暴风雪、寒冰弹幕 |
| 死灵法师 | 伤害加深、微暗灵视、削弱、尸体爆炸、攻击反噬、恐惧、迷乱、偷取生命、吸引、衰老、降低抵抗、黑暗契约 |

### 技能增益效果：放大指定增益，不是全技能增伤

技能增益效果按比例提高指定增益的数值：

`指定增益数值＝原增益数值×（1＋技能增益效果÷100）`

它没有使用范围的 70×X÷（X＋18） 曲线。例如某技能原本提供 +40% 跑速，+25% 技能增益效果会把这项增益算成 +50%，不是额外加 25 个百分点。最终角色属性仍会受叠加方式、取整和各自上限影响。

只有技能明确接入的项目会放大；增益状态的持续时间不能据此默认延长。冰冷、中毒时长等明确接入的例外见下表，不能把“技能增益”理解为技能等级、所有伤害、全部增益或持续时间一起增加。

| 职业 | 技能及明确接入的增益项目 |
|---|---|
| 法师 | 附魔冰霜：附加冰伤、冰冷持续时间与准确率；附魔火焰：附加火伤与准确率；炽烈之径：移动速度；碎冰甲：防御加成与快速格挡速度；寒冰装甲：防御加成与格挡加成 |
| 圣骑士 | 神圣之盾：技能提供的格挡与防御加成；圣剑：武器格挡、增强伤害及附加魔法伤害 |
| 野蛮人 | 大叫：防御加成；战斗体制：当前职业版本提供的生命、法力固定增益；战斗指挥：技能等级增益与增强伤害，技能等级增益会受到整数取整影响 |
| 德鲁伊 | 野性狂暴：移动速度与技能状态提供的生命偷取相关数值；其攻击伤害公式没有因此统一倍增 |
| 刺客 | 速度爆发：移动与攻击速度；能量消解：四系抗性、诅咒抗性与物理抗性；毒牙：附加毒伤数值及其覆盖中毒时长，因此不能仅按增益百分比推算最终每秒毒伤 |
| 亚马逊、死灵法师 | 没有直接受益的本职业技能；装备或升华提供的增益见下方清单 |

特别注意：炽烈之径的地面火伤、两种冰甲的反击伤害、能量盾的吸收比例和耗蓝效率，都不能因为这些技能属于“增益技能”就认定受到技能增益效果放大。格挡或抗性增益提高，也不等于自动提高角色最终格挡／抗性上限。

装备、升华等独立增益也有接入：战争召唤提供的战斗体制（与职业版本公式不同）、次级影散、装备速度爆发、装备能量消解、增援、猛攻、烈风之力、耐力球、时间扭曲、奥术涌动、纷争之源、凋零、制毒宗师、凶猛咆哮、锐眼版烈风之力。它们只放大各自接入的属性，例如增强伤害、三速、行动速度、减伤、抗性、元素专精或穿透；不自动提高叠层数量上限。

技能增益效果、光环效果、诅咒效果是不同属性，不能相互替代。普通光环或诅咒是否增强，应看它们各自的属性公式，不能用技能增益效果代替。

### 技能频率：通常减少间隔，不是提高施法速度

当前接入技能的常见形式是：

`间隔＝原间隔×（1－技能频率÷100）`，最低不低于该技能的间隔下限

这与“每秒次数直接增加同样百分比”不同。例如原间隔 20 帧，+25% 技能频率会将公式间隔降为 15 帧，在没有其他限制时，每秒次数约增加 33.3%；+50% 会降为 10 帧，理论每秒次数翻倍。示例忽略其他机制限制，实际运行按整帧结算，25 帧为 1 秒。

它不采用范围的递减曲线，也不同于快速施法、攻击速度或冷却缩减。角色施法动画更快、技能冷却更短和持续技能攻击更频繁，是不同的机制。

| 职业／来源 | 受益技能 | 影响的间隔 |
|---|---|---|
| 亚马逊 | 爆裂箭 | 集束爆炸的引信延迟，当前基础参数为 2 帧；不是射箭动画速度，也不等于增加爆炸次数 |
| 法师 | 雷云风暴 | 周期攻击间隔，基础表达式为 50－基础点×25÷20，再应用频率 |
| 圣骑士 | 神圣之火、神圣冰冻、神圣冲击、庇护所 | 光环周期以 25 帧为基础，再应用频率 |
| 德鲁伊 | 火山爆 | 伤害间隔以 6－基础点÷10 为基础，再应用频率 |
| 德鲁伊 | 龙卷风 | 重复伤害间隔以 15 帧为基础，再应用频率；不是龙卷风施法速度 |
| 刺客 | 刃之怒 | 连续飞镖间隔以 4 帧为基础，公式最低为 2 帧 |
| 刺客 | 刀刃之盾 | 缩短周期攻击间隔，基础点也会缩短其中的周期 |
| 装备独立技能 | 装备自带刀盾 | 缩短周期攻击间隔，公式最低为 3 帧 |

火魔专属圣火保持每 25 帧（1 秒）一次，没有使用圣骑士圣火的频率公式。其他未列出的技能，也不会因为堆叠技能频率而自动加快施法或攻击。

频率存在整帧档位和技能自身的最低间隔，达到限制后继续堆叠不再等比例提速。它也不会取消重复命中限制，因此“攻击更频繁”不等于对同一个敌人的有效伤害次数必然同比增加。
