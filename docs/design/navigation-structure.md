# 导航二级目录方案（v3 · 已实施）

> 2026-09-13。目标：把原来 22 个平铺标签收成「一级分组 + 二级标签」，降低顶部导航的认知负担。
> v3 已按反馈调整：**更新日志提到一级**、**命运卡牌移入制作强化**、**默认落地页改为赛季页**、**标签写进地址栏（`?tab=`）**。

## 1. 方案

一级 7 项，二级共 22 个标签（与原来一一对应，**没有任何标签被合并或删除**）。
一级中「赛季」「更新日志」只有一页，**直接进入、不显示二级行**。

| 一级 | 图标 | 二级标签 |
|---|---|---|
| **赛季** `S1` | ✦ | （直达国服SOL第一赛季） |
| **更新日志** | ❖ | （直达） |
| **装备资料** | ⚔ | 武器 · 护甲 · 暗金装备 · 符文之语 · 词缀 |
| **制作强化** | ⚒ | 魔方配方 · 圣化 · 腐化 `测试版` · 精华 · 炼狱熔炉 · 命运卡牌 |
| **角色成长** | ✧ | 技能 · 升华 · 核心BD构筑 |
| **玩法模式** | ◈ | 标准模式 · 毁灭模式 `测试版` · 地图 |
| **工具帮助** | ⚙ | 掉落计算器 `体验版` · 技能计算器 · 帮助 |

**交互**：
- 第一行是一级项（当前项高亮为金色），第二行是该组的二级标签（**只有一页的一级项不显示第二行**）。
- **默认落地页 = 赛季页**；地址栏写当前标签 `?tab=xxx`（默认页不带参数），**支持浏览器前进 / 后退**，链接可直接分享。
- 点一级分组会跳到该组**上次停留的**二级标签（新会话则取该组第一个）；记忆在内存里，不写 localStorage。
- 「毁灭」开关保留在第一行最右侧（原来在标签行右侧）。
- 默认落地页仍是 **装备资料 → 武器**，没变。

## 2. 分组理由

| 分组 | 为什么这么放 |
|---|---|
| 赛季 | 赛季页是目前唯一以文档为主体的页面；**更新日志已按要求提到一级**（它属于「站点/内容变更」，不与赛季说明绑定） |
| 装备资料 | 五张表都是「查一件东西是什么」，是 wiki 的主入口，放第二组保证默认落地就在这里 |
| 制作强化 | 魔方 / 圣化 / 腐化 / 精华都是「拿手上的东西去改造」；炼狱熔炉是毁灭模式里的改造装置，放这里而不是玩法模式 |
| 角色成长 | 技能、升华、BD 构筑回答的是「我这个人怎么变强」 |
| 玩法模式 | 标准 / 毁灭是两种模式的规则总览，地图与命运卡牌是模式内的玩法系统 |
| 工具帮助 | 两个计算器 + 使用说明，属于「辅助功能」而不是资料 |

## 3. 我犹豫过的几个点（你可以直接改）

| 标签 | 放在 A | 也可以放 B | 取舍 |
|---|---|---|---|
| **精华** | 制作强化 | 装备资料 | 精华本质是物品，但用途是「重洗稀有物品并锁定词缀」，跟圣化/腐化是一类动作，所以放制作 |
| **炼狱熔炉** | 制作强化 | 玩法模式 | 熔炉是毁灭模式专属装置；但它的内容全是配方，检索时更可能从「我要合东西」进来 |
| **命运卡牌** | 制作强化（已按反馈调整） | 玩法模式 / 装备资料 | 卡牌的用法是「献祭换牌/增殖」，与魔方、熔炉同属「用材料换结果」 |
| **腐化** | 制作强化 | 装备资料 | 与圣化同属改造动作，放一起更自然；代价是「暗金装备」页里的腐化入口不在同组 |
| **帮助** | 工具帮助 | 赛季（单独放） | 帮助只有一页，单独成组太浪费 |
| **更新日志** | 一级直达（已按反馈调整） | 赛季组内 | 提为一级后一眼可见，不再藏在赛季组里 |

## 4. 三个开关（已定）

1. **默认落地页** → **赛季页**（`DEFAULT_TAB = "season1"`）。
2. **一级常显** → 保持常显 7 项。
3. **URL** → 已实现 `?tab=xxx` 深链 + 前进/后退同步；默认页不写参数。

### 地址栏规则

| 行为 | 结果 |
|---|---|
| 打开 `/` | 进赛季页，地址栏保持干净（不带 `?tab=`） |
| 切到任意标签 | `?tab=<key>`，并入历史（可用浏览器后退） |
| 打开 `/?tab=uniques` | 直接进「装备资料 → 暗金装备」 |
| `?tab=` 的值不是已知标签 | 忽略，回落默认页 |

## 5. 实现位置

| 文件 | 改动 |
|---|---|
| `src/App.jsx` | 新增 `TAB_GROUPS`（分组定义）+ `DEFAULT_TAB` + `groupOfTab()`；`TabsBar` 改为两行结构 |
